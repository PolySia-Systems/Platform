# Optional Rendered Assets

Canonical diagrams are the Mermaid files in `../sources/`. This directory
contains 18 SVG exports generated with Mermaid CLI 11.16.0 and the existing
system Chrome executable. No PolySia dependency or runtime configuration was
changed. SVG files must be regenerated from the matching source, reviewed
visually, and committed with the source change.

No PNG export is required for this pack. Do not add a Mermaid renderer to the
PolySia Python runtime or project dependencies.
