# Secrets Notice

This delivery folder intentionally includes a real `.env` file.

Treat this folder as private and confidential:

- Do not upload it to a public repository.
- Do not paste `.env` contents into chat, tickets, logs, screenshots, or reports.
- Share it only with the approved project owner or a trusted operator.
- Rotate keys immediately if this folder is sent to the wrong person.

The `.env` file is included so the recipient can reproduce the Phase 36 live
connectivity state without rebuilding local configuration from scratch.

Safe files to share publicly must be created from this project only after
removing `.env`, live reports, generated artifacts, private keys, API keys,
wallet secrets, and any account-specific output.
